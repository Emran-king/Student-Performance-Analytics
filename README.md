# Student Performance Analytics System

## Project Overview
This project analyzes student performance using Python.

## Features
- Student performance analysis
- Department-wise performance chart
- Subject-wise average marks chart
- Student search by ID
- Pass and fail summary
- Top 5 students report
- Department-wise student count
- Department-wise average marks

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Files
- main.py
- students.csv
- department_chart.png
- subject_chart.png

## How to Run
1. Install Python.
2. Install required libraries:
   pip install pandas numpy matplotlib
3. Run the project:
   python app.py
